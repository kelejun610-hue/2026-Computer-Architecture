# CP1 報告：10_CLIP C 基線與測資設計

## 1. 本次目標
完成 10_CLIP 自訂指令的 C 語言基線（C baseline）與 10 組測試向量設計，建立後續硬體實作的測試基準。

## 2. 設計內容
10_CLIP 的主要功能是做 8-bit 有號數的數值裁切（$rd = \min(\max(rs1, -128), 127)$）。
我們在 `instructions/10_CLIP/c_baseline/clip.c` 裡面用最簡單的條件判斷來寫：
- 如果數值超過 $127$，就直接卡在 $127$。
- 如果數值低於 $-128$，就直接卡在 $-128$。
- 介於中間的正常數字就直接保留原值。

## 3. 結果與分析
我們在 `instructions/10_CLIP/tests/test_vectors.txt` 寫了 10 組測資，包含上下界、零跟故意溢位的數字。實際用 C 程式跑過之後，10 組全部通過（100% PASS），沒有漏掉任何邊界狀況。

## 4. 遇到的問題與解決方法
我們在 GitHub 網頁直接新增 `clip.c` 時，瀏覽器白目自動幫我們把網頁翻譯成中文，結果 C 語言的 `int` 跟 `if` 全都變成中文，導致整個語法爛掉。後來我們手動關掉瀏覽器翻譯，把標準 C 程式碼重新貼上去才搞定。

## 5. 白話說明
簡單來說，CLIP 就是幫數字設一個上下限夾子（-128 到 127）。平常我們做運算時，如果數字太大或太小超過 8-bit 的範圍，資料就會爆掉。這個指令就像是一個自動煞車，數字太高幫你壓到 127，太低幫你拉到 -128，確保資料在安全的範圍內跑。
